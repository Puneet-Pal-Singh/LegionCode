LegionCode is an open-source AI coding-agent workspace. Connect a GitHub repository, choose a provider and model, give the agent a scoped task, and review the resulting code changes before taking a Git action.

<Callout variant="info" title="Private alpha">
  Hosted access is approved manually in small batches. Join the waitlist from
  the [Cloud page](/cloud/). Approved users sign in with GitHub to open the web
  workspace.
</Callout>

## What LegionCode is

LegionCode is built for review-first development:

- **Repository context:** choose the GitHub repository and branch for the task.
- **Provider choice:** connect your own provider credentials and choose a model.
- **Isolated work:** keep concurrent tasks in separate writable workspaces.
- **Visible activity:** follow agent messages and tool activity as the task runs.
- **Code review:** inspect changed files and diffs before committing, pushing, or opening a pull request.

Repository commands do not run in the browser. The browser is a control and review surface; execution happens in the runtime attached to the workspace.

## Core workflow

1. Request private-alpha access.
2. Sign in with the approved GitHub account.
3. Select a repository and base branch.
4. Connect a provider credential and choose a model.
5. Start a task with one concrete outcome.
6. Follow the agent response and tool activity.
7. Review the changed files and diff.
8. Ask for revisions or take an explicit Git action.

Each task keeps its own conversation and writable workspace. Parallel tasks can start from the same repository without sharing uncommitted files.
